# Doubly Linked Lists Project

This project implements a doubly linked list in C.

## Files
- 0-print_dlistint.c → prints all elements in a doubly linked list
- lists.h → header file containing struct definition and prototypes

## Description
A doubly linked list is a linear data structure where each node has:
- data (n)
- pointer to next node
- pointer to previous node
