# Hash Tables Project

This project implements a hash table in C as part of the ALX Low Level Programming curriculum.

## Description

A hash table is a data structure that stores key-value pairs and allows fast data retrieval using a hash function.

## Files

- hash_tables.h → Header file containing structures and prototypes
- 0-hash_table_create.c → Function to create a hash table
- 0-main.c → Test file for the implementation
